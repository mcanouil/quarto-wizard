# Use a Brand

A brand holds the logos, colours and fonts of an organisation.
Quarto Wizard downloads a brand into your project, so every document can use it.

## How to Use a Brand

1. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
2. Run **"Quarto Wizard: Use Brand"**.
3. Select a source: GitHub, URL or Local.
4. Choose the workspace folder.

Quarto Wizard writes the brand files to the `_brand/` directory of your project.

[Use Brand](command:quartoWizard.useBrand)

[Full guide](https://m.canouil.dev/quarto-wizard/getting-started/installing-extensions.html#using-brands)
